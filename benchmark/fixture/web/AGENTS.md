# web

The shop's page: plain JavaScript ES modules, no dependencies, no build step.

- Layout: `index.html`, `src/*.mjs` (`format.mjs` formats prices, `main.mjs` renders the page), tests in `tests/`.
- Checks: `node --test` (Node 18+, run from this directory; it finds `tests/*.test.mjs`).
- Commits: Conventional Commits.
