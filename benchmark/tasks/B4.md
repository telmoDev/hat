# B4 · A frontend feature

Repos: web · Kind: feature

## Request
Add a cart badge to the page. Export `badgeText(items)` from a new `web/src/badge.mjs`, where `items` is a list of
`{id, quantity}`: it returns `""` for an empty cart, the total quantity as a string from 1 to 99, and `"99+"`
above 99. Show it in the header of `web/index.html` in an element with id `cart-badge`. Add tests.

## Criteria
- O1 `badgeText` returns `""` for an empty cart and the total quantity as a string up to 99
- O2 `badgeText` returns `"99+"` above 99
- O3 `index.html` has the `cart-badge` element in its header
- O4 the repo's tests pass
