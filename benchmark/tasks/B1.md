# B1 · Explore how a cart total is computed

Repos: api · Kind: exploration (no code changes)

## Request
Explain how `api` computes a cart's total, end to end: which functions take part, in what order, and how the
bulk discount and coupons are applied. Change no code.

End your answer with one fenced `json` block, exactly in this shape, about the code as it is now:

```json
{"functions": ["<module.Class.method or module.function>", "..."],
 "totals": {"A": <cents>, "B": <cents>, "C": <cents>},
 "coupon_applied_times": <how many times the SAVE5 amount is taken off cart B's total>}
```

where the totals are what `Cart.total` returns today for: A = 2 Pens, no coupon; B = 1 Bag with coupon
`SAVE5`; C = 10 Pens with coupon `SAVE5`.

## Criteria
- O1 the functions named are the ones the total goes through (`cart.Cart.total`, `cart.Cart.subtotal`,
  `pricing.apply_discounts`, `pricing.bulk_discount`, `pricing.coupon_discount`), and no other
- O2 the three totals are what the code returns today
- O3 it says how many times the coupon is taken off cart B's total
- O4 no code changed
