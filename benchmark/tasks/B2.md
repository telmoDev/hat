# B2 · Add an endpoint

Repos: api · Kind: feature

## Request
Add `GET /products/<id>` to `api/server.py`: for a product that exists, answer 200 with its JSON (the same fields
as in `GET /products`); for an unknown or non-numeric id, answer 404 with `{"error": "not found"}`. Keep
`GET /products` as it is, and add tests.

## Criteria
- O1 `GET /products/2` answers 200 with the Notebook's fields, as listed by `GET /products`
- O2 an unknown id (`/products/99`) and a non-numeric one (`/products/abc`) answer 404 with `{"error": "not found"}`
- O3 `GET /products` is unchanged
- O4 the repo's tests pass
